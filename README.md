# Wheel of Suffering

My home workout app for a pull-up bar and a pair of dumbbells, with a Dungeons & Dragons twist. Spin the wheel for a random exercise, do the set, and let the interval timer call the next one.

**Tech stack:** React, Vite, Web Audio API, localStorage

## Features

- **Customisable wheel:** add, edit, remove or untick exercises, and set the reps or time for each. Filter the wheel by equipment (pull-up bar, dumbbells, bodyweight).
- **Interval timer:** choose how often (every N minutes) and how many rounds. It rings a bell each round and can spin the wheel for you automatically. It also keeps your screen awake while it runs, on browsers that support it.
- **Quest log:** mark each set as done to keep a running log of today's workout.
- **Sound effects:** wheel ticks, a result chime and a timer bell, all generated with the Web Audio API (no audio files).
- Everything is saved in your browser, so your wheel and settings are still there next time.

## Getting started

```bash
npm install
npm run dev
```
